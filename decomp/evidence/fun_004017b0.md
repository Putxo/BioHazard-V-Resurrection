## Recovered behavior

The function first rejects `destination_size < length`. Otherwise it copies the 8-byte global seed from `0x01655B48..0x01655B4F` into local feedback state. This seed read happens even when `length == 0`; zero length then returns 0.

For each input byte, with lane `i & 7`:

- `plaintext = ciphertext XOR feedback[lane]`
- write plaintext to destination
- replace `feedback[lane]` with the original ciphertext byte

Thus this is the inverse companion of `FUN_00401730`, which emits ciphertext and feeds the emitted ciphertext back into the same 8-byte state.

The implementation keeps `module` and `subsystem` as `UNKNOWN`; no unsupported higher-level file-format or subsystem name is asserted.
