- `0x00423170` is a thin owner method: calls `0x004206D0`, then tail-jumps to `0x0041D910` with the same owner.
- `0x00423180` gates a similar update: requires owner DWORD `+0x2C >= 0x64`, checks current global stage/session record derived from `0x0165BBB0`, rejects IDs above `0x497`, and rejects a global state whose `+0x18 == 2`; otherwise calls `0x00420960` then tail-jumps `0x0041D910`.

## FUN_004231D0

- Enters/exits subsystem around global `0x0165C148` using `0x0050AE50(4)` and `0x0050B020`.
