## ABI reconstruction

- `ECX` is the source refcounted-string holder.
- Stack argument 1 is the destination holder pointer.
- Stack argument 2 is forwarded unchanged to recovered `FUN_00407FD0` and is therefore `const char* suffix`.
- `ret 8` confirms two 32-bit stack arguments under x86 thiscall.
- `EAX = ESI` immediately before return proves the result is the destination holder pointer.

## Recovered behavior

1. Read `source.pointer`.
2. Store it into `destination.pointer` unconditionally. Native code does **not** release a pre-existing destination value; caller sites use scratch/temporary destinations.
3. If the copied pointer is non-null, increment its leading 32-bit reference count.
4. Call recovered `FUN_00407FD0(destination, suffix)`.
5. Return `&destination`.

The only branch inside this 34-byte wrapper is the source-null branch at `0x0040804B`. It skips only the add-ref; the FD0 call remains unconditional. Null/empty-suffix early exits and the portable allocator/concatenate guards belong to FD0 and are tested here as delegated behavior.
