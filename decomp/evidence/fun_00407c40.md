## Calling convention and recovered contract

The body is an x86 no-frills `thiscall` wrapper with one 4-byte stack argument:

1. Load the sole stack argument from `[esp+4]`.
2. Preserve `this` in ESI.
3. Push the argument unchanged and call recovered `FUN_00402360` with the original ECX/`this`.
4. Ignore the callee return value, restore EAX from saved `this`, and return with `ret 4`.

The repository already recovers `FUN_00402360` as a constructor for `FUN_00402360_String`, a one-pointer reference-counted string holder taking `const char* input`. It clears the holder for null/empty input or builds the ref-counted block for non-empty input.

Because `FUN_00407C40` passes its own `this` directly to that constructor without an offset, the portable reconstruction aliases `FUN_00407C40_Object` to the already recovered `FUN_00402360_String`. No additional class or subsystem-specific semantic name is invented.

## Branches, guards, and tests

`FUN_00407C40` has no native conditional branch and no imported/service call of its own. Therefore no synthetic C40-specific null/service guard is added.

The unit test covers, through the wrapper:

- null input delegated to the native-equivalent early return of `FUN_00402360`;
- empty input delegated to the same constructor early-return family;
- the portable host allocator-unavailable guard owned by `FUN_00402360`;
- a non-empty construction path, including exact `length + 0x0C` allocation size, `0x10` alignment, refcount `1`, stored length, copied bytes, and return of the original `this`.

The wrapper's explicit return of `&destination` matches the native `mov eax,esi` even though the delegated host implementation currently also returns its destination.
