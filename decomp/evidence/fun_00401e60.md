## Recovered behavior

- Runs platform pre-initialization and caches that boolean at global byte `0x01655B56`.
- If Steam indicates relaunch is required, logs the relaunch message and returns `false`.
- If Steam initialization fails, logs the failure message and returns `false`.
- Installs warning hook callback `0x00401210`.
- Sets overlay notification position to `3`.
- Stores the mapped country id from `FUN_004015D0`.
- Reads and stores the two dwords of the SteamID.
- Ensures the achievement singleton exists if global `0x01655B58` is not already set.
- Uses `FUN_00401950` language id result to choose displayed product/registry title strings.
- Returns `true` on successful initialization or the non-Steam fallback path.
