## Imported-call identity

PE import decoding resolves IAT RVA `0x00F71178` (VA `0x01371178`) to Win32 `EnterCriticalSection`.

The wrapper passes exactly `this+4`. On 32-bit Windows a `CRITICAL_SECTION` occupies 0x18 bytes, which exactly fills `this+0x04..this+0x1B`; the tested byte at `this+0x1C` immediately follows it. The reconstruction therefore preserves a 0x18-byte opaque critical-section region at offset +4 without inferring the surrounding class identity.

## Branch behavior

Native control flow is exact:

1. If byte `this+0x1C` is nonzero, skip the global-byte read and call `EnterCriticalSection(this+4)`.
2. Otherwise read global byte `0x016E2090`.
3. If that global byte is zero, return immediately with no imported call.
4. If it is nonzero, call `EnterCriticalSection(this+4)`.

The early return at `0x00407B29` is native and is covered by the unit test where both flags are zero.
