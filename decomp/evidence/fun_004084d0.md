## RTTI-proven class and object layout

Parallel FUN_00408490 evidence independently decodes the MSVC RTTI:

- vtable 0x01541F54 -> type descriptor ".?AVlogic_error@std@@";
- base vtable 0x01541FAC -> type descriptor ".?AVexception@std@@".

Thus FUN_004084D0 is the std::logic_error destruction layer.

The recovered constructor object is reused directly:

~~~text
FUN_00408490_Object
+0x00  vtable
+0x04  base_message
+0x08  base_owns_message
+0x0C  FUN_004082E0_String message
~~~

The embedded validated SSO string maps to:

- object+0x10..+0x1F: 16-byte storage union;
- object+0x20: message length;
- object+0x24: message capacity.

Capacity below 16 means inline storage at object+0x10. Capacity at least 16
means object+0x10 stores the heap pointer.

## std::logic_error message cleanup

The destructor first reinstalls std::logic_error vtable 0x01541F54.

If embedded message capacity is at least 16, it passes the heap pointer at
object+0x10 to target aligned release routine 0x0125145C. The branch at
0x004084DD skips only this free; it does not return.

The embedded SSO message is then reset exactly to:

- capacity = 15;
- length = 0;
- first inline-storage byte = 0.

The allocator-state dword at object+0x0C and the remaining 15 bytes of the
union are not cleared by the native instruction stream.

The final E9 is an exact tail-call to 0x01251BE3:

~~~text

01251BF7  59                       pop ecx

~~~

This is the std::exception base destructor corresponding to RTTI vtable
0x01541FAC. It installs the base vtable and, when base_owns_message at +0x08
is nonzero, passes base_message at +0x04 to the opaque release body
0x0125677A.

Therefore the complete observable destructor behavior is:

1. install std::logic_error vtable 0x01541F54;
2. optionally free the embedded SSO heap;
3. reset the embedded SSO message;
4. install std::exception vtable 0x01541FAC;
5. conditionally release the owned base message;
6. return through the tail-called base destructor.

## Tests and host-only guards

The portable reconstruction aliases FUN_004084D0_Object to the already
recovered FUN_00408490_Object and exposes only two target-only cleanup seams:

- aligned free at 0x0125145C;
- base-message release at 0x0125677A.

Missing callbacks are host-only guards. They suppress only the unavailable
external call; they do not invent an early return.

tests/unit/test_fun_004084d0.cpp covers:

- native capacity<16 branch bypassing SSO heap free;
- native base_owns_message==0 branch bypassing base-message release;
- heap-backed message cleanup;
- exact ordering: logic_error vtable during free, SSO reset, then exception
  vtable during base-message release;
- exact heap pointer and base-message token forwarding;
- preservation of the untouched embedded allocator-state dword;
- completely missing host services without synthetic early return;
- missing free callback while base-message release still runs;
- missing base-message callback while SSO heap free still runs.
