## Recovered behavior

The native routine has exactly two early exits and one release path:

1. Read the block pointer stored at `this+0x00`.
2. If the pointer is null, return immediately.
3. Decrement the block's leading 32-bit reference count.
4. If the resulting count is nonzero, return immediately.
5. If the count is zero, obtain global allocator/service `0x01652F28` and
   invoke virtual slot `+0x18` with the original block pointer.
6. Return without clearing the holder pointer.

The host reconstruction aliases the already-recovered
`FUN_00402360_String` / `FUN_00402360_Block` structural types. A small
injected service exposes only the final allocator free for unit testing. The
native target assumes that global allocator is present; the host null-service
check exists solely to avoid an invalid test-harness call after the exact
refcount transition.
