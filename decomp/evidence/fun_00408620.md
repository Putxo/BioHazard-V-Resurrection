## ABI and recovered behavior

The function takes no stack arguments and returns the immediate value in EAX.
All decoded callers use the return value as an object/address token, for
example by moving EAX to ECX before invoking another thiscall helper.

The recovered contract is therefore:

~~~text
uintptr_t FUN_00408620()
~~~

The behavior is exactly:

1. place `0x016F0230` in EAX;
2. return.

The portable implementation returns the same fixed address token as
`std::uintptr_t`. No host pointer is dereferenced and no higher-level class
name is inferred.
