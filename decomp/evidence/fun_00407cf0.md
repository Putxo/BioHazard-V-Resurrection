## ABI and recovered contract

The body is a one-argument x86 `thiscall` wrapper:

1. read the sole stack argument from `[esp+4]`;
2. preserve `this` in ESI;
3. push the input pointer;
4. explicitly clear the one-pointer holder at `[this]`;
5. delegate construction to the already recovered `FUN_00402360`;
6. restore EAX from the saved `this` and return with `ret 4`.

`FUN_00402360` is already recovered as the constructor for `FUN_00402360_String`, a one-pointer reference-counted string holder taking `const char* input`. Because CF0 passes its own `this` directly with no offset, the portable reconstruction aliases `FUN_00407CF0_Object` to that structural holder instead of inventing an unsupported class name.

The explicit `destination.pointer = nullptr` in the portable wrapper represents the native `mov dword ptr [esi],0` even though the shared host implementation of `FUN_00402360` also clears the holder at entry.
