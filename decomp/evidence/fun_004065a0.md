## Early exits and reconstruction choice

The original 42-byte body contains no conditional branch and no early-return path: it always emits the diagnostic marker, calls `0x004061F0`, cleans all eight pushed dwords, and returns.

The portable host reconstruction adds a null-service guard and a null-dispatch guard so tests can execute without the original engine. The null-dispatch guard is placed after the optional trace callback to preserve the original operation order as closely as possible. A missing host trace callback does not suppress the resource dispatch. These guards are harness-only behavior and are explicitly tested; they are not claimed as original binary control flow.

`FUN_004061F0`, `FUN_00406540`, and `FUN_00406570` are parallel assignments and are not modified by this recovery. `0x004061F0` is treated only as an opaque injectable dispatch service.
