## ABI, layout and helper contracts

The final `ret 8` proves two stack dword arguments. ECX is preserved in ESI
as the object pointer, proving a thiscall-shaped contract:

~~~text
FUN_00408070_String* FUN_00408070(
    FUN_00408070_String& value,
    uint32_t position,
    uint32_t count)
~~~

Observed object layout:

- storage union begins at `this+0x04`;
- logical length is `this+0x14`;
- capacity is `this+0x18`;
- capacity below `0x10` selects the inline 16-byte storage;
- capacity `>= 0x10` selects the heap pointer stored in the union.

The call at `0x0125136C` is the MSVC string-position exception path. The
same exact binary contains both the RTTI name `std::out_of_range` and the
literal `"invalid string position"`, matching the position check at
`0x00408078..0x0040807E`.

The four-argument helper at `0x01251AD1` validates a destination pointer,
destination size, source pointer and copy count before forwarding the actual
move. D90 passes precisely:

- destination = data + position;
- destination size = capacity - position;
- source = data + position + erase_count;
- copy count = length - position - erase_count.

The portable reconstruction uses `std::memmove` for this observed overlap-safe
move after preserving the same bounds and string invariants.

## Behavioral reconstruction

1. If `position > length`, raise
   `std::out_of_range("invalid string position")`.
2. Compute `remaining = length - position`.
3. Clamp `count` to `remaining` using the native unsigned comparison.
4. If the resulting erase count is zero, return `this` without resolving
   inline/heap storage.
5. Resolve storage via the exact `capacity < 0x10` SSO threshold.
6. Move the remaining tail left across the erased range.
7. Decrease length by the erase count.
8. Write the terminating NUL at the new length.
9. Return `this`.

A complete decoded rel32 scan of the exact .text section finds exactly **2**
direct calls to `0x00408070`, at `0x00408311` and `0x0040831B`.
Those calls occur in the self-source branch of the adjacent higher-level
string operation and independently confirm the two-argument mutation contract.
