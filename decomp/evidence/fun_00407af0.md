## RTTI proves the semantic class

The vtable written by the target is at `0x01541F48`.

- The preceding Complete Object Locator pointer at `0x01541F44` is `0x0156312C`.
- That COL names type descriptor `0x015672D8`.
- The descriptor's decorated name is `.?AVbad_alloc@std@@`, i.e. `std::bad_alloc`.
- The next vtable slots are `0x00407B90` (deleting-destructor shape) and `0x01251BF9` (message/what-like accessor).
- The base vtable installed by `0x01251B8B` is `0x01541FAC`, consistent with the adjacent `.?AVexception@std@@` RTTI descriptor at `0x015672F4`.

Therefore the target is the `std::bad_alloc` copy-constructor wrapper over the `std::exception` copy constructor. The portable reconstruction deliberately uses a project-local ABI-shaped object rather than binding to the host compiler's `std::bad_alloc` ABI.
