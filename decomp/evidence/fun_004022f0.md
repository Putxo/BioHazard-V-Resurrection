## Recovered behavior

The four functions operate on a refcounted heap string layout:

- `+0x00`: reference count
- `+0x04`: string length
- `+0x08`: NUL-terminated byte string

`FUN_00402360` allocates `length + 0x0C` bytes through global allocator service `0x01652F28` virtual slot `+0x14`, using alignment `0x10`.
`FUN_004023E0` decrements the old reference count, frees through slot `+0x18` when it reaches zero, then copies the source pointer and increments the new reference count.
