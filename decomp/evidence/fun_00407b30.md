## Behavior and object layout

1. If byte `this+0x1C` is nonzero, the global flag is not read and `LeaveCriticalSection(this+4)` is called.
2. Otherwise global byte `0x016E2090` is read.
3. If the global byte is zero, the function returns immediately without the imported call.
4. If the global byte is nonzero, `LeaveCriticalSection(this+4)` is called.

The paired `FUN_00407B10` evidence establishes the opaque 0x18-byte critical-section storage at `this+0x04..this+0x1B`, immediately before the tested byte at `this+0x1C`. No surrounding class identity is inferred.
