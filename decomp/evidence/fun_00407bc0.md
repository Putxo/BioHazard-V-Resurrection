## Recovered contract

The function is a one-argument callee-cleaned x86 `thiscall` membership test:

1. dispatch virtual slot `+0x10` on `this` to obtain the first node;
2. load the supplied key object's dword at `+0x04`;
3. compare it with the current node's dword at `+0x04`;
4. return true immediately on a match;
5. otherwise advance through the node link at `+0x10`;
6. return false when the chain is exhausted.

The native return value is boolean in `AL`: matches execute `mov al,1`, misses execute `xor al,al`. Callers test `AL` directly, so the portable signature uses `bool`.

The adjacent recovered `FUN_00407C00` independently walks the same `node+0x04/node+0x10` structure using the same vslot `+0x10`, but returns `this` or null instead of a boolean. This sibling provides a local structural cross-check without assigning an unsupported class name.

## Portable reconstruction and tests

Only the virtual `this+vslot 0x10` operation is injected through a service callback so the linked-chain logic can be tested without a proprietary game vtable. Host-only safety exits are added for:

- missing services;
- missing first-node callback;
- a null first-node result.

These exits are not claimed to exist in the native body. Native-path tests cover:

- immediate first-node hit / early true return;
- later-node hit through `+0x10` links;
- chain exhaustion / false return.

The first-hit test deliberately gives the matching node an invalid non-null `next` sentinel; passing proves the recovered early return does not follow the chain after a match.
